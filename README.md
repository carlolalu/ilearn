# Learning

Gathering of learning exercises and "notes" in **Rust, C++ and C**. This repo is for personal use only and has been constructed over many years, consequently it is chaotic. Still it was decided to expose it, to show my practice with some programming languages I have been learning.

## Structure

| Directory | Language | Origin |
|---|---|---|
| [c/](./c) | C | *C: From Theory to Practice* exercises |
| [cpp/](./cpp) | C++ | *learncpp.com* + additional exercises |
| [rust/](./rust) | Rust | *[Official Rust Book](https://doc.rust-lang.org/book/)*, *Programming Rust, 2nd Ed.* and the [tokio tutorial](https://tokio.rs/tokio/tutorial)|

Each folder maintains its own `README.md`, build scripts, and tests.
